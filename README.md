## 🚀 Projetos em destaque

### 💰 InvestWallet — Back-end
API REST para gestão de carteiras de investimentos, construída com Clean Architecture e DDD para manter as regras de negócio isoladas da infraestrutura. Conta com autenticação stateless via JWT (com blacklist no Redis), motor de recomendações determinístico baseado em score, perfil de risco e diversificação, além de integração opcional com Gemini AI para enriquecimento textual das recomendações.

**Stack:** Java 21 · Spring Boot 3 · MySQL · Redis · JWT · Flyway · MapStruct · Swagger/OpenAPI
[Ver repositório](https://github.com/MaikonDsGomes/IA-wallet-BE)

### 📊 InvestWallet — Front-end
Interface web para visualizar e gerenciar a carteira de investimentos, consumindo a API do back-end. Exibe KPIs da carteira (valor total, rentabilidade e lucro acumulado), score de qualidade com análise de diversificação, risco e performance vs. CDI/IBOV, distribuição por classe de ativo, posições individuais com variação diária e recomendações geradas pela API. Permite registrar compras e vendas de ativos diretamente pelo dashboard. Autenticação com e-mail/senha ou Google (OAuth), com refresh token automático via interceptor.

**Stack:** Angular 20, TypeScript, RxJS
[Ver repositório](https://github.com/MaikonDsGomes/IA-wallet-FE)

### 🤖 API Agêntica para Aferição de Pontos de Função
Pipeline agêntico que automatiza a aferição de Pontos de Função seguindo a metodologia APF/IFPUG. Lê histórias de usuário diariamente de um bucket S3, envia o lote para o modelo Gemini 2.5 Flash com instruções determinísticas e retorna classificação funcional estruturada (tipo de função, operação, PF estimado, score de qualidade). Os resultados são persistidos via API REST e exportados de volta ao S3, com notificação de conclusão via SNS.

**Stack:** Python · Google Gemini API · AWS S3 · AWS SNS · Boto3
[Ver repositório](https://github.com/Grupo-02-2026-SpTech/IA-Agent)
